- Versioned fixtures / data provenance: `fixtures/corpus.jsonl`, every Bash call in the `~/.claude/projects/*/*.jsonl` transcripts, with fields command, is_error, ts and session, and secrets redacted. `fixtures/synthetic.json`, written with the Write tool and holding hand-built positive, negative, edge and adversarial cases. A SHA-256 hash of each fixture is recorded in the report.
- Candidate design and files (sandbox only): `inline-script-guard.cjs` reads the PreToolUse JSON from stdin. It inspects only `tool_input.command`, using a quote-aware scan with no eval or exec. It looks for (1) an unquoted heredoc whose body contains `\\`, `\$`, `${`, `$(` or a backtick, (2) a double-quoted interpreter argument (`python -c`, `node -e/-p`) containing the same characters, (3) double-quoted `echo`/`printf` output redirected to a `.json/.js/.py/.cjs/.mjs` file or piped to an interpreter, with the same characters, and (4) an inline interpreter body of more than 25 lines. On a match it prints a warning. On no match, or on any internal error, it prints nothing and exits 0, so it fails open.
- Test cases: Positives are the 4 reconstructed failures, real errored calls from the corpus that were hand-labelled as quoting failures, and variants. Negatives are quoted heredocs (`<<'EOF'`), single-quoted `python -c` with backslashes, git commit heredocs, plain grep/ls, and Windows paths in ordinary arguments. Edge and adversarial cases are an `EOF` inside a string, escaped quotes, `$` at the end of a line, very long commands, and malformed JSON input.
- Metrics and predeclared acceptance thresholds: Recall on the labelled positives must be ≥ 90%, and on the synthetic positives 100%. The warning rate on corpus calls that succeeded must be ≤ 5%. The warning rate on the synthetic negatives must be 0. There must be no crash on malformed input, which means exit 0 and empty output. p95 runtime must be ≤ 150 ms per call, including Node startup.

- Security/privacy review: The detector never executes command text. The corpus is redacted for API keys and tokens before it is written. The mechanism reproduction runs only commands I wrote myself, which print or parse fixed strings in a temp directory.
