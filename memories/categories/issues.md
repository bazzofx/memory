# Issues — previous errors, root causes and fixes

Load when: a command, edit, build or test fails (grep for the error text or tool first), or before a risky step in one of the topics below.
Format: `- [YYYY-MM-DD] <rule>. Why: <root cause / what went wrong>.` Newest first within each topic; add a `##` topic only when none fits.

## Shell & scripting (Windows + Git Bash)
- [2026-11-22] Never write Python/JS — or JSON/test fixtures — containing backslashes, `${...}` or nested quotes inline in a Bash command (heredocs, `printf`/`echo`, `python -c`/`node -e`). Write the file with the Write tool, then run/use it. **Quoted heredocs (`<<'EOF'`) and single quotes do NOT protect backslashes here.** The Bash tool (verified on Claude Code 2.1.329, Windows/Git Bash, 2026-11-23) collapses each run of N backslashes to ceil(N/2) before bash runs, unless the next char is `"`. So `'A\\B'` arrives as `A\B`. Bash then applies its own `${`/`$(`/backtick/`\\` processing in double quotes and unquoted heredocs. Why (seen repeatedly): `'\\'` arrived as `'\'` even in a `<<'EOF'` heredoc (SyntaxError); a fixture's `C:\\ai` became `C:\ai` (invalid JSON, sometimes silently with exit 0); a template literal `${esc(k)}` broke bash command substitution; a big inline `s.replace(...)` script failed on line 25; inline Python edits silently wrote control characters, because `"\\b"` / `"\\v"` became backspace / vertical tab (a regex `\b` stopped matching; a doc path became `\Luci<VT>oices`; 2026-11-22/24). After any inline edit that touched backslashes, check with `grep -c $'\x08'` / `$'\x0b'`. Evidence: `dreams/experiments/DREAM-001/run-20261123-01/report.md`.
- [2026-11-24] PowerShell: anything after `powershell -Command "<script>"` is appended to the script text, not passed as `$args`. Put values into the script (validated numbers only), and send untrusted text on stdin (`[Console]::In.ReadToEnd()`). Why: the Windows TTS fallback silently said nothing ("Unexpected token '0'"), because stderr went to DEVNULL.
- [2026-11-22] Build paths with `os.path` / `pathlib` or `.replace(chr(92), '/')`, never hard-coded `'\\'` splits. When passing a path from Git Bash to Windows node/python, convert it with `cygpath -m` (`/c/Users/…` → `C:/Users/…`). Why: hard-coded split hit a SyntaxError; node's `existsSync('/c/…')` returned false, so a hook test looked like it silently did nothing.
- [2026-11-22] Don't hand-edit JSON via string replace; load → modify → `json.dump`. Then validate with `python -m json.tool file.json`. Why: a manual edit left a missing comma ("Expected ',' or ']' … line 132").
- [2026-11-22] `mv`/rename/`rm -rf` (or a tool's rmtree) of a folder can fail with "Device or resource busy" / WinError 32 on Windows when a process, the app, **or the Bash tool's own cwd** is inside it. `cd` out first, close/stop whatever uses it, or copy then delete, and check the result before continuing. Why: skill folder rename failed and later steps read a path that didn't exist; a PyInstaller rebuild failed to clear `build/luci-dist/.../_internal` because a previous `cd` left the shell there (2026-11-24).
- [2026-11-22] `ls` on several paths exits 2 if any one is missing — that's not a real failure; use `ls … 2>/dev/null` or test with `[ -e path ]`.
- [2026-11-22] Check the working directory before relative paths ("File does not exist. Note: your current working directory is …"). Prefer absolute paths.

## Editing files
- [2026-11-22] Re-Read a file right before Edit/Write if anything (user, linter, a script I ran, a shell `mv`/`cp`) may have touched or moved it, and copy `old_string` from that fresh Read, not from memory. Why: "File has been modified since read", "String to replace not found", and "File has not been read yet" after moving files with `mv`.

## Python environments & secrets
- [2026-11-22] Run project scripts with the project's own interpreter/venv (check for `.venv`, `venv`, `requirements.txt`) before assuming a package is missing. Why: an upload script crashed importing `googleapiclient` under the wrong Python.
- [2026-11-24] On Windows, when one thread is blocked reading a **stdin pipe** (Node `spawn(..., {stdio: 'pipe'})`, or `tail -f file | python`), another thread importing a compiled extension (numpy, onnxruntime, ctranslate2/faster-whisper) can hang forever. Import those modules on the main thread before starting the stdin reader or background loaders. Why: Luci's voice stayed "loading" forever only when started with piped stdin. `python -X faulthandler` showed the thread stuck in numpy's `create_module`, and a 0.6 s main-thread preload fixed it.
- [2026-11-24] `transformers` "Could not import module 'X'" hides the real error. Import the submodule directly (e.g. `import transformers.models.albert.modeling_albert`). "operator torchvision::nms does not exist" means torchvision doesn't match torch; install the matching one (torch 2.8 → `torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128 --no-deps`). Why: Kokoro TTS failed to load because torchvision 0.20.1 sat next to torch 2.8.
- [2026-11-24] Before documenting an install, check that `requirements.txt` lists every non-stdlib import. Why: Luci's file had `faster-whisper` and `pynput` commented out while the code imported them, so a fresh install would have had no mic or hotkey.
- [2026-11-24] PyInstaller: don't `collect_all()` big packages (onnxruntime, ctranslate2, faster_whisper) when building from a crowded/global Python; use `collect_data_files` + `collect_dynamic_libs`, and `excludes` for numba/llvmlite, pandas, scipy, PIL, sqlalchemy, fsspec, torch. Check `du -sh _internal/*` after building. A frozen exe also ignores `python -u`, so add `[("u", None, "OPTION")]` as EXE's options when a parent reads its piped output. Why: Luci's bundle went 440 → 313 MB (llvmlite alone was 115 MB), and Kairo's Luci log view stayed empty until the unbuffered option was added.
- [2026-11-22] If a script needs an env var (API key), check it exists first (`[ -n "$VAR" ]`) and ask the user — never invent or hard-code a key. Why: OPENROUTER_API_KEY / apiZenWarriorOpenRouter were unset; scripts exited.

## Built-in browser & terminal tools
- [2026-11-22] Call `read_page` or `find` before clicking by `ref`. Why: "ref map not initialized".
- [2026-11-22] Long-running servers go in `run_in_background` (or launch.json + preview_start), not `run_in_terminal` typed lines that may be read as unfinished.

## UI & CSS
- [2026-11-24] UI: stray page scrollbars after adding a chart came from a Tailwind `sr-only` table (position:absolute) with no positioned ancestor. It was placed against `<body>` and made the document taller than the viewport. Fix: put `relative` on the wrapper. Diagnose with JS: compare `document.documentElement.scrollHeight` with `innerHeight`, then check `el.offsetParent` of absolute elements.

## Testing
- [2026-11-24] A CLI that reads stdin (e.g. `luci serve`) exits at once when started in the background (`exe &` / `( … &)`) from the Bash tool, because stdin is at EOF, so the empty log looks like a crash. Test it in the foreground with piped stdin: `(sleep 30; echo ":quit") | timeout 60 app.exe …`. Why: two silent "failed" runs of the frozen luci.exe were really clean EOF exits.
- [2026-11-22] When a test script prints all cases and exits 1, find *which* case failed (print only failures + expected vs got) before changing code.
